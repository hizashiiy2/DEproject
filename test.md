Slide/Section Timer
The user breaks the presentation into sections, like intro, theory, demo, conclusion. The app shows if they are ahead or behind time for each part.
Practice History
Every rehearsal is saved with time, date, duration, and notes. The user can see if they are improving over multiple attempts.
Random Question Cards
The app has a set of prepared exam-style questions. After rehearsing, the user clicks “random question” and gets one to answer, like a mini oral exam.
